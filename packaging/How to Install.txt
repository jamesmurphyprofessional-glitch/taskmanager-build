How to install Task Manager
===========================

You do not need Xcode, Terminal, or any extra software.

1. Double-click “TaskManager Distro.zip” if it is still a zip file.
   A folder will appear.

2. Open that folder.

3. Double-click “Install Task Manager”.
   (If your Mac asks whether to open it, choose Open.)

4. Task Manager is copied into Applications and opens by itself.

If your Mac says Task Manager cannot be opened
----------------------------------------------
That is normal for apps not from the App Store.

1. Open System Settings
2. Click Privacy & Security
3. Scroll down
4. Click Open Anyway next to Task Manager

To uninstall later
------------------
Open the Applications folder, drag Task Manager to the Trash.
