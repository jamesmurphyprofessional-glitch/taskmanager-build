Task Manager — beta
===================

A Task Manager for Apple Silicon Macs (macOS 14 or later).

Install
1. Double-click “Install Task Manager”
2. If macOS blocks it: System Settings → Privacy & Security → Open Anyway

You do not need Xcode.

This is a beta project. It is not yet legally registered.
Please do not share this file.

Developed by James Murphy.

Uninstall
Quit Task Manager, then drag /Applications/TaskManager.app to the Trash.
